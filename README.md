# 01 Personal Portfolio

A responsive HTML and CSS webpage project for the Web Development assignment.

## Run locally
1. Download or clone this folder.
2. Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a new GitHub repository for this project.
2. Upload `index.html` and `style.css` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Wait for the published URL to appear in the Pages section.

## Customize before submitting
- Replace sample email addresses and social links with your own.
- Update the sample names, descriptions, prices and other demo content as needed.
- Add your own screenshots or project details if required by your faculty.

This project uses HTML and CSS. Google Fonts are loaded online; the layout and styling work without them using fallback fonts.
